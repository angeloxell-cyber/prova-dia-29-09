# Mundo dos Dinossauros

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End para Web.

## Autor

Angelo Ferreira da Silva

## Sobre o projeto

O projeto Mundo dos Dinossauros é um site desenvolvido utilizando HTML5, com o objetivo de apresentar informações sobre dinossauros, fósseis, paleontologia e os períodos da Era Mesozoica.

O site possui diferentes páginas conectadas por um menu de navegação, permitindo acessar os conteúdos de forma simples.

## Páginas do projeto

- `index.html` - Página inicial do projeto.
- `especies.html` - Apresenta espécies de dinossauros e suas características.
- `eras.html` - Apresenta informações sobre os períodos da Era Mesozoica.
- `fosseis.html` - Apresenta informações sobre fósseis e paleontologia.
- `contato.html` - Contém um formulário de pesquisa sobre dinossauros.

## Estrutura de pastas

O projeto está organizado da seguinte forma:

- `html/` - Páginas HTML do projeto.
- `img/` - Imagens utilizadas nas páginas.
- `audio/` - Arquivo de áudio utilizado no projeto.
- `video/` - Arquivo de vídeo utilizado no projeto.

## Recursos utilizados

O projeto utiliza recursos do HTML5, incluindo:

- Tags semânticas como `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`;
- Tabelas;
- Formulários;
- `details` e `summary`;
- `figure` e `figcaption`;
- `abbr`;
- `mark`;
- `del` e `ins`;
- `blockquote` e `cite`;
- `progress` e `meter`;
- Áudio;
- Vídeo;
- Imagens;
- Links para navegação entre as páginas.

## Formulário

A página de pesquisa utiliza diferentes recursos de formulário HTML, como:

- `date`;
- `file`;
- `range`;
- `datalist`;
- `required`;
- `placeholder`.

## Arquivos locais

As imagens utilizadas pelo projeto estão armazenadas na pasta `img`.

O áudio utilizado está armazenado na pasta `audio`.

O vídeo utilizado está armazenado na pasta `video`.

## Como executar

Para visualizar o projeto:

1. Extraia a pasta do projeto.
2. Abra a pasta `html`.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize o menu de navegação para acessar as outras páginas.
